# プレビュー拡張を共通の外部プレビュー方式にする

WasabiPad本体のコードに組み込まれたものだけを標準プレビューとし、それ以外のプレビュー機能は配布元によらず外部プレビューとして同じ仕組みで扱う。利用者が実行ファイルを選んで登録し、WasabiPadは設定と拡張子ごとの選択、外部プロセスの起動、HTML/SVG生成物の表示を共通管理する。パッケージ形式や自動配布は必須にせず、実行ファイルと関連ファイルの導入・更新は利用者が管理する。

外部プレビューは複数登録でき、同じ拡張子の候補から利用者が一つを選ぶ。選択がない場合は標準プレビューを使う。各外部プレビューには利用者が識別用の表示名を設定できる。表示名は一覧や候補の識別に使い、実行や信頼許可の識別には使わない。外部プログラムは初回実行前に確認し、許可状態は外部プレビューごとに保存する。実行ファイルまたは引数を編集した場合は再確認する。登録・編集画面の実行コマンドはエディタ側の登録コマンドと同じ一つの入力欄と確認用プレビューを使うが、実行方法はそれぞれの既存契約を保つ。拡張子・生成形式などの設定は残す。

既存の音楽プレビュー機能は一旦削除し、旧音楽アドインのデータはアドインデータ領域の保留フォルダへ移して読み込まない。既存の外部アダプタ設定は移行時に削除し、利用者が再登録する。詳細は[共通外部プレビュー計画](../plans/0020-common-external-addins.md)に記す。

2026-10-02追記: 旧音楽アドインの保留フォルダへの移行は不要となったため、起動時の移行処理と空フォルダの自動生成を廃止する。既存フォルダと資産は自動削除しない。詳細は[エディタ検索結果と検索入力操作](../plans/0022-editor-search-results-and-input-actions.md)に記す。

外部プレビュー生成物は通常のプレビューキャッシュと分けた一時保存先に置き、既定はOSの一時フォルダ配下とする。保存先を変更しても実行中のジョブは元の場所に残し、過去に使った保存先も起動時の所有済みジョブ掃除に使う。更新は外部プレビュー専用ボタンから行い、未保存の文書は保存確認後に再実行する。F5の既存動作は変えない。WasabiPadが直接起動するコンソールアプリはコンソールを非表示にし、標準出力・標準エラーを捕捉する。失敗時はWasabiPad内の外部プレビュー実行ログに残す。アダプターが別のコンソールやGUIウィンドウを起動する場合、その表示制御はアダプター側に属する。
