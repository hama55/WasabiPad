# 編集図の背景画像を共有し、表示時に参照を解決する

編集図は SVG として保存し、背景画像は共有ファイルへの相対参照で保持する。通常の画像表示では SVG 内の外部画像を読み込めないため、WasabiPad は表示時のみ画像込みの SVG をメモリ内で生成する。図ごとに背景画像を複製または埋め込み保存する方式よりディスク使用量を優先し、他の Markdown アプリでの背景付き表示と画像込みの書き出しは初期版の保証範囲外とする。

2026-10-09 の追加合意では、編集図 SVG を WasabiPad で直接開いた場合にも同じ表示時参照解決を適用する。保存ファイルへの画像埋め込みは行わない。外部画像参照に対応する他アプリ向けにも標準の相対参照を維持し、SVG と参照画像を一緒に持ち運ぶ。外部参照を制限する HTML img 等での表示は保証しない。
