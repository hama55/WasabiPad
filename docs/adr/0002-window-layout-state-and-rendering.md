# ウィンドウ状態とペイン表示を分離して安定表示を確定する

OSの最小化・最大化・復元はOSの復元範囲を信頼し、ファイルツリーやプレビューの開閉・全画面表示とは別の状態として扱う。画面領域の変更は正の寸法だけを最新値として確定し、復元・リサイズ・DPI変更などが落ち着いた後にレイアウトをまとめて更新する。非同期の内容表示は準備中の現在表示を維持し、最新世代の準備が完了した場合だけ置き換える。準備中は旧表示への操作を止め、初回表示には読込中を示すことで、復元直後の古い寸法による白抜けや空白を防ぐ。

## Considered Options

- OS状態とペイン状態を一つの状態として保存する: 最小化やOSの復元処理がアプリの開閉状態を意図せず変えるため採用しない。
- 0寸法をそのままレイアウトへ反映する: 最小化中の一時的な測定値で表示を壊すため採用しない。
- 非同期処理が完了する前に新しい内容へ置き換える: 古い更新の完了で空白や古い表示が戻るため採用しない。
- 無効寸法を毎フレーム無期限に再測定する: 最小化中のCPU使用量が増えるため、数フレーム後は低頻度タイマーへ切り替え、復元または破棄まで継続する。

## Consequences

狭い画面では本文を優先して補助ペインを自動退避するが、利用者が選んだペイン状態は保持され、画面が戻れば再表示できる。表示確定が次のフレームや資産読込を待つため初回表示が少し遅れる場合があるが、無効寸法・連続操作・復元直後でも不完全な画面を確定しない。
