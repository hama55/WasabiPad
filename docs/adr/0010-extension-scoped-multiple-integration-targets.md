# 有効拡張子ごとに複数の連携先を登録する

既存の連携エディタ・連携プレビューは1つのキーに1コマンドだけを持ち、画像プレビューは `image` に集約されていた。ADR 0006の編集と表示の境界、保存済み実ファイルだけを対象にする制約は維持し、各有効拡張子に順序付きの複数の連携先登録を持たせる。

- 設定キーは既存互換の小文字・ドットなしの具体的な有効拡張子とし、画像も `apng`、`avif`、`bmp`、`gif`、`ico`、`jpeg`、`jpg`、`png`、`svg`、`webp` を個別に扱う。
- 設定画面の追加ボタンで同じ拡張子の登録を増やし、登録順をエディタ文書操作メニューの順序にする。1件なら既存の「連携エディタで開く」を直接表示し、2件以上なら同名のサブメニューにまとめる。
- 各登録は任意の連携先名とコマンド文字列を持つ。重複、実行ファイルの存在、オプションの妥当性を事前検査せず、保存したコマンドをそのまま実行する。名前が空欄ならコマンド文字列を表示する。
- `.txt` に連携設定がない初回だけ、`メモ帳`・`notepad.exe "{file}"` の登録を1件作る。利用者が削除した登録は再作成しない。
- 既存の `image` 設定は具体的な画像拡張子へ展開し、既存の個別設定を上書きしない。移行後は `image` を設定キーとして使わない。

この決定はADR 0006のうち、連携プレビューの形式キーを `ViewerFormat` にする記述を更新する。連携エディタと連携プレビューを分けること、未保存文書・仮想項目・機密アーカイブを外部へ渡さないこと、明示起動だけにすることは変更しない。
