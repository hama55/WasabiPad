# SQLiteプレビューで一時SQLビューを表示する

SQLiteプレビューに、入力した単一の読み取り用 `SELECT` を結果表として確認する機能を追加する。既存の「任意SQLを実行しない」決定（[ADR 0015](0015-sqlite-preview.md)）をこの範囲に限って更新し、接続ごとにメモリ上のTEMP VIEWを作成する。SQLはプレビュー中のUIメモリにだけ保持し、元DBや設定へ保存しない。新しいSQLは成功した時だけ現在の一時ビューを置き換える。

各ページ要求は従来どおりDBを読み取り専用で開き直すため、その要求内で一時ビューを再作成する。厳密な行数表示は維持するが、複雑なSELECTは行数計算とページ取得で複数回評価され、外部更新後のページ間で結果が変わることがある。順序はSELECTに `ORDER BY` がある場合だけ保証される。

SQLコンソール、複数ビュー、定義の永続化、編集・保存は対象外とする。
