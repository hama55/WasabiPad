# SQLiteプレビューの適格性をヘッダーで判定する

SQLiteプレビューは、大文字小文字を区別しない .db、.sqlite、.sqlite3 の実ファイルを候補とし、先頭16バイトがSQLite 3の標準ヘッダーである場合だけ表示する。拡張子がSQLite系でも内容が異なるファイルをSQLiteエラーへ誤誘導せず、他の拡張子やアーカイブ内容まで走査しないため、対象拡張子を絞ったうえでヘッダーを確認する。ヘッダー一致後も既存の読み取り専用SQLite処理で開けることを確認し、ヘッダー不一致は従来の通常形式判定へ戻す。

この判定は自動プレビューと既存のビューワー形式判定に共通して適用する。フォルダ、未保存文書、アーカイブ内項目は引き続き対象外とする。ヘッダーが一致していてもSQLiteとして読めないファイルは、既存の読取エラーを表示する。
