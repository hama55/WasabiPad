# エディタの「画面内」は表示中の論理行範囲を対象にする

2026-10-08：「画面内」を「選択のみ」に置き換え、この決定を廃止した。現在は本文で選んだ範囲に完全に収まる一致だけを一括置換する。検索・置換欄へのフォーカス移動や検索一致への移動では置換対象の範囲を保持し、本文で選び直すと更新する。未選択・閲覧専用では無効。検索条件は既存の一括置換と共通で、置換後も変更後の範囲を選択し、Undo一回で全変更を戻せる。

以下は旧仕様の記録。

「画面内」では、押下時点で本文領域に縦方向で一部でも表示されている論理行の全一致を、現在の選択中文書内で一括置換する。横方向に隠れている同じ論理行の文字は含め、描画先読み行と画面外の行は除外する。画面のピクセル単位で文字位置を切るより既存の行単位検索・一括編集を再利用でき、折り返し表示でも一貫した境界になるため。
