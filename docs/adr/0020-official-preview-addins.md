# 公式プレビューアドインを後付けする

この方針は[ADR-0022](0022-common-external-addins.md)で置き換えた。以下は当時の決定記録。

楽譜の表示・再生は公式の後付けアドインとして提供し、本体は導入管理と既存プレビューへの接続、外部ツール実行・生成物受渡しを担当する（2026-09-26合意、詳細は[計画メモ](../plans/music-preview-addins.md)を参照）。標準配布を軽量に保つため楽譜ライブラリと音源は追加パッケージに置き、LilyPond本体は利用者が別途導入する。初回は公式アドインを信頼された実行コードとして扱い、第三者製や動的Rust DLLの読み込みを対象外とすることで、必要な後付け機能に範囲を絞る。
