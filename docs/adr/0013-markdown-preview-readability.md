# Markdownプレビューの可読性を設定可能にする

Markdownプレビューは、見出しを下線で区切らず、本文・見出し・引用・コード・表には読みやすいブロック間隔を設ける。列挙項目は項目間を小さく詰め、文章の行間とは区別する。本文の行間は既定値1.65の倍率として設定画面から1.4〜2.0の範囲で変更でき、変更は表示中のプレビューへ即時反映してJSONへ保存する。

## Considered Options

- 見出しの下線を残す: 他のMarkdownプレビューとの見た目の差が大きく、見出しの階層を文字サイズと余白で表せるため採用しない。
- 行間を固定する: 文書や利用者の読みやすさに応じて調整できないため採用しない。
- Markdown本文へ空行要素を挿入する: Markdownの構造を変え、通常改行設定や外部アプリとの表示差を増やすため採用しない。

## Consequences

Markdownの解析結果とGFM互換基準は変更せず、可読性はviewer.cssのレイアウト規則で調整する。設定値は既存の設定復元・保存・リセット経路を使い、インラインプレビューでは既存のiframeメッセージ経路で同期する。HTMLプレビューのスクリプト無効化や、Markdownの安全なHTML制限は変更しない。
