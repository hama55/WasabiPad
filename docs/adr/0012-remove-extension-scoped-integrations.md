# 拡張子別連携設定を削除し登録コマンドへ集約する

拡張子ごとに連携エディタ・連携プレビューを登録する設定は、必要な拡張子を個別に登録する負担が大きいため削除する。既存の保存データに残る旧キーは削除せず読み込まない。代替として、拡張子に依存しない登録コマンドを設定モーダルで編集・削除・並べ替えできるようにし、エディタでは保存済みファイル向けの `{file}` と選択文字列向けの文字列プレースホルダーを右クリックメニューから実行する。

この決定はADR 0006・0007・0010の実装対象を更新する。登録コマンドは `file` / `string` の種別ごとに順序を保持し、設定変更は既存の設定保存経路へ即時反映する。
