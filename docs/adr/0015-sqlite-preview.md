# SQLiteプレビューを採用する

`.sqlite` と `.sqlite3` の保存済み実ファイルを、既存のプレビュー領域で読み取り専用表示する。Rust側に `rusqlite` の `bundled` 構成を同梱し、固定クエリでテーブル・ビュー・SQLite内部テーブルと `sqlite_schema` を読む。利用者がSQLを実行したり、データを編集・保存・エクスポートしたりする機能は追加しない。

## 決定

- 対象は大文字小文字を区別しない `.sqlite` / `.sqlite3` の通常実ファイルだけとする。未保存文書とアーカイブ内項目は対象外とする。
- `NULL`、BLOBのバイト数、4,096文字で省略する長文を専用のセル表現で表示する。
- 初期表示行数は100。設定「SQLiteプレビューの表示行数」で正の整数を上限なしで指定でき、再読み込みから反映する。DOM追加は200行単位に分割する。
- ロック、破損、暗号化などの読取失敗は理由と再読み込み操作をプレビュー領域へ表示する。

## 却下した選択肢

- 外部sqlite3.exe、WASM、Tauri SQLプラグイン: 配布・実行環境の依存を増やすため採用しない。
- SQLiteファイルのコピーや独自キャッシュ: 表示の鮮度と保存場所の管理を増やすため採用しない。
- SQLコンソールや編集機能: 読み取り専用プレビューの範囲を超えるため採用しない。

## サイズ結果

基準値に対して、実装後の release 成果物は exe `9,844,736` bytes（基準 `8,748,032` bytes、`+1,096,704` bytes）、NSIS installer `3,080,875` bytes（基準 `2,541,428` bytes、`+539,447` bytes）だった。exeは1 MiBを超えたが、方式と増分を確認したうえで利用者が採用を承認した。

## 結果

既存の通常プレビュー・InlinePreview・生成IPC契約・設定保存経路を再利用し、SQLite専用の読み取りモジュールとテーブル表示だけを追加する。`0014-skip-sqlite-preview.md` は、採用前の判断記録として履歴に残す。
