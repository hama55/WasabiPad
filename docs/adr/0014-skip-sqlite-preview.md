# SQLiteプレビューを見送る

SQLite形式のファイルを標準プレビューで確認する機能は、既存のプレビュー経路の再利用だけでは足りず、SQLite解析、IPC契約、テーブル表示の追加が必要になるため、現時点では実装しない。新しいSQLite依存を同梱した場合のexeと配布物への影響も事前に許容範囲内と保証できず、「簡単に実装でき、exeサイズを大きく変えない」という条件に合わない。

## Considered Options

- SQLite解析ライブラリを追加する: 依存と配布物サイズの増加が発生し、許容範囲を保証できないため採用しない。
- SQLite解析処理を自作する: 保守対象が増え、簡単な実装という条件に合わないため採用しない。
- バイナリまたはテキストとして表示する: SQLiteのテーブルやレコードを確認できず、SQLiteプレビューの目的を満たさないため採用しない。

## Consequences

`.sqlite` と `.sqlite3` は意味のあるSQLiteプレビューを提供せず、既存の汎用ファイル扱いを維持する。再検討する場合は、読み取り専用・既存プレビュー領域・初期100行で設定変更可能・設定値の上限なし・対応外の理由をプレビュー領域に表示する条件を満たし、exeとインストーラーの増分を実測できる方式に限る。
