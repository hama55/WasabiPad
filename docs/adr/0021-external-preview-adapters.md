# 外部プレビューアダプタで楽譜プレビューを外出しする

この方針は[ADR-0022](0022-common-external-addins.md)で置き換えた。以下は当時の決定記録。

ABC・LilyPond の表示と再生を、本体に形式別の処理を増やす方式ではなく、利用者が用意した外部プログラムで生成する方式へ移す。標準配布と本体固有コードを軽くし、他の拡張子にも同じ入口を使えるようにする判断である。既存の公式プレビューアドイン（[ADR-0020](0020-official-preview-addins.md)）は移行完了まで現行機能として残し、本判断はその楽譜向け構成の移行先を定める。

外部プレビューアダプタは拡張子、実行ファイル、引数テンプレートを持ち、保存済み通常ファイルの `{file}` と実行ごとに異なる `{output}` を外部プログラムへ渡す。外部プログラムが入口 HTML または SVG と付属資産を作り、その内容・恒久資産の配置と参照・恒久資産の削除に責任を持つ。WasabiPad は生成物を表示し、自ら割り当てた実行用一時フォルダだけを表示終了後に片付ける。登録コマンドとは設定も実行結果の用途も統合しない。

外部 HTML は trusted external HTML mode とし、JavaScript、`file://`、絶対パス、外部リソースを方針上許可する。一方、再生に不要な親画面の DOM と Tauri IPC は許可しない。通常の HTML 文書の静的 `srcdoc` 表示は緩和しない。WebView の制約により許可だけでは参照が動かない場合もあるため、動的 HTML は両権限の遮断と必要な参照・再生を実機で立証できるまで提供しない。

## 帰結

- WasabiPad は ABC/LilyPond 用の音源・再生ライブラリや不足資産を導入管理しない。利用者が外部プログラムと必要資産を用意する。
- 保存済み通常ファイルだけを対象とし、現在の編集中内容からの楽譜更新は引き継がない。移行と旧コード削除は、表示・MIDI再生とこの差分の受容を確認してから行う。
- Markdown/CSV のエディタ連動、SQLite の対話型表示、登録コマンドとの統合は対象外。SQLite の外部化は別判断とする。

実装手順と未確認事項は [計画0019](../plans/0019-external-preview-adapters.md) に記す。
