# exe サイズ削減の計測（2026-10-04）

機能を維持したまま、未使用の Tauri コマンドと依存機能をビルド対象から除外した。

## 計測条件

- 変更前コミット: `f4aaf632bbe11636f93ad103446bb592c4f18d30`
- 対象: Windows の `target/release/wasabipad.exe`（インストーラーではない）
- 各段階のコマンド: `npm run tauri -- build --no-bundle`
- Rust: `rustc 1.91.1 (ed61e7d7e 2025-11-07)`
- Cargo: `cargo 1.91.1 (ea2d97820 2025-10-10)`
- Tauri: `2.11.5`、tauri-build: `2.6.3`、CLI: `2.11.4`
- リリース最適化、検索ライブラリの速度優先設定、フロントエンドのソースは変更していない。

## 結果

| 段階 | bytes | MB（10進） | 前段階からの削減 |
| --- | ---: | ---: | ---: |
| 作業開始時の既存 exe | 10,295,296 | 10.295296 | — |
| 変更前の再ビルド | 10,295,296 | 10.295296 | 0 |
| 未使用コマンドの除去 | 9,278,464 | 9.278464 | 1,016,832 |
| 依存整理も適用 | 8,957,952 | 8.957952 | 320,512 |

合計 **1,337,344 bytes（12.99%）削減**。10,000,000 bytes 未満になった。

## 変更と機能維持の根拠

- `build.removeUnusedCommands` を有効化。現在の静的 capability で許可されていない Tauri 内部・プラグインの IPC コマンドを除去する。既存の capability 定義は維持した。
- Tauri の既定 feature を明示し、未使用の `dynamic-acl` だけを無効化。`wry`、`compression`、`common-controls-v6`、`x11`、`dbus` と既存の `protocol-asset` は維持した。アプリに実行時の `add_capability` 呼び出しはない。
- 未使用の直接依存 `url` を削除。推移依存としては残るため、これ単独のサイズ削減効果はない。
- 独自の IPC コマンド77個とプラグイン登録は変更していない。固定済みの tauri-macros 2.6.3 は、アプリ独自 ACL がない現構成ではアプリのコマンドを除去しない。

未使用コマンド除去は動的 ACL を考慮しない。将来、実行時の権限追加を導入する場合は、feature とコマンド除去設定を併せて再検討する。[Tauri の公式説明](https://v2.tauri.app/concept/size/#remove-unused-commands)
