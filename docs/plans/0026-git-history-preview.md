# Git履歴プレビュー

状態: 最終合意済み。実装・自動検証完了。Tauri実機での確認は未実施。

## 確定した範囲

- ファイルツリーの `.git` を選択して、標準プレビューに履歴を表示する。
- 通常フォルダの選択動作は維持する。
- worktree などの `.git` ファイルも入口に含める。
- 現在のブランチのコミット履歴を閲覧する。
- コミットの日時・作者・メッセージを表示する。
- コミット選択で変更ファイル一覧、ファイル選択で行単位の差分を表示する。
- 更新ボタンで履歴を再取得する。
- 初期版は閲覧専用。未コミット変更の表示、ブランチ切替、Gitを書き換える操作は含めない。
- 現在のブランチからたどれるコミットを含め、新しい順に表示する。最初は100件、「さらに読み込む」で100件ずつ追加する。
- マージコミットは第1親との比較を表示する。最初のコミットは空の状態と比較する。
- 行単位の変更は統一差分で表示する。追加は緑、削除は赤で区別する。
- バイナリは変更情報だけ表示する。大きな差分は上限まで表示し、省略を明示する。

## 第3ラウンドと画面構成の合意

- `.git` 選択時は直前の通常文書の本文・未保存編集を維持し、プレビューだけ切り替える。フォルダの展開も維持する。
- 通常ファイルを開いたら、そのファイルのプレビューに戻す。
- コミット前は「コミットがありません」。detached HEAD では状態と短いコミットIDを表示し、その地点から履歴をたどる。不正な `.git` は理由を表示する。
- 更新後も履歴内に残る選択コミット・ファイルを維持する。ブランチが変わった場合は新しい履歴の先頭コミットへ切り替える。
- Gitプレビュー内部は上下に分割する。
- 上段はブランチ表示とコミット一覧。コミットを展開したツリーに変更ファイルを表示する。
- 上段のファイル選択に応じて下段へ差分を表示する。
- ブランチの表示は既合意の閲覧専用範囲に従う。切替操作は含めない。

## 第4ラウンドの合意

- インストール済みのGitを読み取りに利用する。見つからない場合はプレビュー内に案内を表示する。
- 分割比率は初期値で上40％・下60％。境界のドラッグで変更でき、比率を保存する。
- 初回は最新コミットを展開し、最初の変更ファイルの差分を表示する。
- タブへ戻ったときは選択・展開・スクロールを保持する。
- アプリ再起動ではGitの閲覧状態を復元しない。

## 第5ラウンドの合意

- 1ファイルの差分は1 MiBまたは2万行の、先に達したところまで表示する。超過時は「差分の一部を省略」と表示する。
- 複数コミットの同時展開を許可する。
- 展開・折りたたみだけでは下段の差分を変更せず、ファイル選択で切り替える。
- 変更ファイルのないコミットは「変更ファイルなし」と表示する。

## 実装手順

1. 合意した操作と例外のBDDを先に追加する。
2. 既存の選択・プレビュー経路を使ってGit対象の入口と読み取り処理を追加する。
3. 上段のコミットツリー、下段の統一差分、上下分割と閲覧状態の保持を追加する。
4. 関連テスト・全体テスト・型検査・生成IPC整合性・Rust検査・差分検査を実施し、変更をレビューする。
5. 実機確認の実施有無を明示し、確認済みの範囲を報告する。

## 実装で守る境界

- 履歴の追加読込は初回取得時のHEADを基準にする。更新操作で基準を取り直す。
- コミット・ファイル・タブの切替後に、以前の読取結果を現在の表示へ反映しない。
- 差分はコミットに保存された内容を比較し、作業フォルダの現在の内容を混ぜない。
- Gitの読取ではリポジトリを書き換えず、ネットワークからの自動取得や外部差分プログラムの実行を行わない。
- 既存の更新・全画面・閉じる操作を利用する。全画面切替でGitの選択状態を失わない。
- 追加・削除は色だけでなく記号でも判別でき、ツリーはキーボード操作に対応する。

## 受入確認の予定

BDDの公開確認窓口は、ツリー選択からプレビューへの切替、Git読取API、プレビュー画面の操作の3つで合意済み。

- `.git` ディレクトリとworktreeの `.git` ファイルからの表示、未保存本文の保持、通常ファイルへの復帰。
- 履歴の100件追加、読込中のHEAD変更、更新時の選択維持・ブランチ変更。
- 最初のコミット・マージ・追加・削除・名前変更・変更ファイルのないコミットの表示。
- バイナリ・大きな差分・コミット前・detached HEAD・不正な `.git`・Git未導入の表示。
- 連続選択・更新・閉じる・タブ切替の表示競合、分割位置・全画面・キーボード操作。

## 調査

- `.git` ディレクトリと `.git` ファイルはファイルツリーの通常項目として列挙される（`core/src/folder.rs:33-53`）。
- 現在のディレクトリ行クリックは展開操作であり、プレビュー開始経路はない（`ui/sidebar.ts:1095-1100`）。
- ファイル行の選択は文書を開く経路を通る（`ui/main.ts:1152-1155`）。
- 既存のGit読み取り依存はない。外部プロセス実行の既存パターンを利用して、インストール済みGitから読み取る方針とする。
