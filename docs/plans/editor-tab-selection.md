# 選択状態に応じた Tab 操作

状態: 実装・自動検証済み。ネイティブ Tauri 上の手動操作は未確認。

## 合意したルール

判定は以下の優先順とする。「行」は折り返し表示の段ではなく論理行を指す。

| 選択状態 | Tab の結果 |
| --- | --- |
| マルチキャレット・矩形選択 | 各選択範囲をタブ文字で置換する。選択のない位置にはタブ文字を挿入する |
| 通常選択で複数行を選択 | 対象各行の先頭にタブ文字を挿入する |
| 通常選択で一行全体を選択 | その行の先頭にタブ文字を挿入する |
| 通常選択で一行の一部分を選択 | 選択範囲をタブ文字で置換する |
| 選択なし | キャレット位置にタブ文字を挿入する |

- 一行全体とは、先頭空白を含めて行頭から行末まで選んだ状態。改行の選択は不要。
- 選択終端が次行の先頭なら、その次行はインデント対象に含めない。
- マルチキャレット・矩形選択の置換優先は、一行全体や複数行を含む場合にも適用する。
- 選択方向によって結果を変えない。
- Shift+Tab の仕様変更は今回の対象外。

## 実装前との差と実装範囲

実装前の行インデント判定は選択開始が行頭かどうかに依存していた。
そのため、行途中からの複数行選択が置換になり、行頭からの一行部分選択がインデントになっていた。
通常選択では、対象行数と一行全体の選択かどうかで判定するよう変更した。

現行の複数キャレットは複数の挿入位置を保持し、各位置に独立した選択範囲を持たない。
この仕様の記録だけで複数選択範囲を保持する新機能の追加は決定しない。
既存の複数キャレットと矩形選択の編集経路を使う。

確認対象: `ui/editor.ts` のキー処理、`ui/editor-mutation.ts` の編集経路、
`ui/editor-edit-plan.ts` の行インデント計画、および対応する既存テスト。

## 受け入れ例

各例を Given / When / Then のテストとして確認する。

- Given 選択なし、When Tab、Then その位置にタブ文字を挿入する。
- Given 一行途中の部分選択、When Tab、Then 選択文字だけをタブ文字で置換する。
- Given 行頭から行途中までの部分選択、When Tab、Then 選択文字だけをタブ文字で置換する。
- Given 改行を含まない一行全体の選択、When Tab、Then 行頭にタブ文字を挿入し本文を残す。
- Given 行途中から次行途中までの選択、When Tab、Then 両行の行頭にタブ文字を挿入し本文を残す。
- Given 一行全体とその改行の選択、When Tab、Then 次行を除いてインデントする。
- Given 三行目の先頭を終端とする複数行選択、When Tab、Then 一・二行目だけをインデントする。
- Given 逆向きの通常選択、When Tab、Then 同じ対象文字・対象行に適用し選択方向を維持する。
- Given 複数キャレット、When Tab、Then 各位置にタブ文字を挿入する。
- Given 矩形選択、When Tab、Then 行インデントより矩形範囲のタブ置換を優先する。
- Given 折り返された一行の一部分だけの選択、When Tab、Then 表示上の複数段でも部分選択として置換する。

空行は選択範囲がなければ「選択なし」として扱う。
Tab 一回の編集は Undo 一回で元に戻せることも確認する。
