# 貼り付け画像の表示幅設定

状態: 合意済み・実装済み（2026-10-08）。実アプリでの目視・OSクリップボード確認は未実施。

## 確定事項

- 設定画面で貼り付け画像の表示幅を変更できるようにする。既定値は900px。
- 幅指定を無効にして、生成するHTMLタグのwidth属性を省略できるようにする。
- 幅指定が有効な場合、生成タグの幅は設定値と元画像の幅の小さい方とする。
- 表示幅の変更で保存画像を縮小・圧縮しない。
- 変更後の貼り付けから適用し、既存タグは変更しない。設定は再起動後も保持する。
- 編集可能な文書の拡張子を問わず適用する。
- 挿入形式、代替テキスト、保存形式・保存先・命名の変更は今回の対象外。

## 設定画面・入力・例外処理

- 設定画面の「エディタ」に「貼り付け画像の幅を指定」と「表示幅の上限（px）」を配置する。
- 幅指定は既定で有効。無効時は数値入力を無効化し、最後の有効な数値を保持する。
- 数値は1〜10000の整数。空欄・0・負数・小数・範囲外は保存せず、直前の有効値を保持する。
- 旧設定の項目欠落は幅指定有効・900px。不正な保存値は既定値へ戻す。
- 元画像の幅を取得できない場合は画像の貼り付けを続け、width属性を省略する。推測した幅で拡大しない。
- 幅指定なしの場合は寸法取得を省略する。

- 保存画像の内容、既存タグ、文書画像フォルダの扱いを維持する。
- 実際の設定画面とクリップボード貼り付けは別途実アプリで確認する。

## 実装の接続点

- `ui/editor.ts` の画像貼り付け共通処理で幅を決定する。
- `ui/settings.ts` の型・既定値・読込検証と既存保存経路を利用する。
- `ui/settings-panel.ts` のエディタ設定と共通数値入力を利用する。画像幅の範囲を明示する。
- 新規の寸法取得処理は貼り付けBlobから幅を得る最小の処理とし、取得に使うリソースを解放する。
- 用語は `CONTEXT.md` の「貼り付け画像の表示幅」を使用する。今回の設定追加にはADRを作らない。
