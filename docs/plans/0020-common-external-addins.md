# 共通外部プレビュー計画

## 目的

標準プレビュー以外のプレビュー拡張を、配布元や対象形式によらず一つの外部プレビュー方式で登録・選択・実行する。まず設定画面のコマンド編集をエディタ側の登録コマンドと揃え、その後に旧音楽プレビュー経路を取り除く。

## 合意した境界

- WasabiPad本体のコードに組み込まれたプレビュー機能だけを「標準プレビュー」と呼ぶ。それ以外はWasabiPad配布でも第三者配布でも「外部プレビュー」とする。
- 外部プレビューは利用者が実行ファイルを選んで登録する。ZIP、マニフェスト、自動ダウンロード、アプリによる実行ファイル更新は必須にしない。
- WasabiPadは登録情報と拡張子ごとの選択を管理し、外部プロセスを起動してHTMLまたはSVGの生成物を表示する。実行ファイルや恒久資産の導入・更新は利用者が管理する。
- 外部プレビューは複数登録できる。同じ拡張子に複数候補がある場合は利用者が一つを選ぶ。選択がない場合は標準プレビューを使う。
- 初回実行前に、選択した外部プログラムを利用者が信頼して実行する確認を行う。許可は外部プレビューのIDごとに保存し、実行ファイルまたは引数を編集したときは取り消す。
- 登録コマンドと外部プレビューは編集画面のコマンド入力と確認用プレビューを共通化するが、プロセス起動と引数解釈の契約は混ぜない。外部プレビュー編集には拡張子、生成形式、優先順位などの固有設定を残す。
- 既存の音楽プレビュー機能を削除する。旧音楽アドインのデータはアドインデータ領域の保留フォルダへ移動し、自動検出・読込・実行をしない。
- 既存の外部アダプタ設定は新方式へ自動変換せず削除し、利用者に再登録してもらう。
- 標準プレビューの既存形式とSQLiteの対話型プレビューはこの外部化の対象にしない。

## 編集画面

- 登録コマンドの設定画面とエディタ側の登録・編集画面で、同じ入力欄と「実行文字列（確認用）」プレビューを使う。プレビューは代表値を使った読み取り専用表示で、保存も実行もしない。
- 外部プレビューの「実行プログラム」と「引数」に分かれた入力を一つのコマンド入力欄へまとめる。保存時は既存の引数パーサーで実行ファイルと引数配列に分け、シェルを経由しない既存の起動動作を保つ。
- 外部プレビューの確認用プレビューは、代表的な入力ファイルと出力先を使って置換後の起動文字列を表示する。
- 外部プレビューの拡張子、生成形式（HTML/SVG）、標準プレビューとの優先順位は既存の設定として維持する。

## 実行と選択

- 保存済みの通常ファイルを対象とする。実行ファイルを直接起動し、引数は配列として渡す。シェル経由にはしない。
- 入力ファイルと実行ごとに異なる出力先を外部プレビューへ渡し、成功終了と生成物の存在・形式を確認してから表示する。
- 実行世代を識別し、文書切替や再実行後に古い結果を表示しない。WasabiPadが作った実行用一時領域だけを所有者として片付ける。
- 複数の外部プレビュー候補の選択状態は拡張子ごとに保存し、未選択時は標準プレビューを選ぶ。標準形式との競合時は外部プレビューごとの優先順位設定を反映する。

## 移行手順

1. 登録コマンド設定に代表値の確認用プレビューを表示し、エディタ側と同じ編集要素を使う。
2. 外部プレビュー編集のコマンド欄を一つにまとめ、確認用プレビューを加える。外部プレビュー固有設定は維持する。
3. 旧外部アダプタ設定を削除する移行処理を加え、旧音楽アドインデータを保留フォルダへ移す。保留データを読み込む経路は残さない。
4. 音楽プレビューのUI、実行・表示経路、旧カタログ・管理コード、専用設定を削除する。共通外部プレビュー機能に必要な共有処理は残す。
5. 設定画面、プレビュー形式選択、ファイルツリーなどの入口が標準プレビューまたは共通外部プレビュー選択へ一貫して接続することを確認する。
6. `ADDINS.md`を実装後の実際の仕様に合わせて更新する。

## 受け入れ条件

- 登録コマンドを設定画面から開いたときにも、代表値による「実行文字列（確認用）」が表示され、プレビューだけでは保存・実行しない。
- 外部プレビュー編集にコマンド入力欄が一つだけ表示され、保存後も実行ファイルと引数配列が従来の規則で渡る。
- 外部プレビューの拡張子・生成形式・優先順位の設定が編集後も保持される。
- 同じ拡張子に複数の外部プレビューを登録でき、利用者は候補を一つ選べる。標準形式との競合時は優先順位が反映され、候補未選択時は標準プレビューが使われる。
- 初回実行時に外部プレビューごとの確認を行い、実行ファイルまたは引数の編集後は再確認する。
- 旧音楽プレビューのUIや実行経路がなく、旧音楽アドインの保留データは実行されない。
- 旧外部アダプタ設定は自動移行されず、利用者は再登録できる。
- 標準プレビューとSQLiteの対話型表示に既存の変更が入らない。

## 対象外

- 外部プレビュー配布サイト、マニフェスト、ZIP形式、署名カタログ、自動更新
- 実行ファイルのインストール・更新・削除管理
- 音楽プレビューの再実装（共通外部プレビュー方式が整った後の別作業）
- 標準プレビュー全形式やSQLite対話型表示の外部化
