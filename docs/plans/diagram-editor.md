# 図の編集と Markdown 表示

状態: 合意済み。実装済み。自動テスト・型検査・ビルドで検証。実 Tauri の画面確認は未実施。

## 確定した仕様

- 右クリックの入口名は、新規作成・既存画像への注釈・再編集のすべてで「図を編集」に統一する。
- 白紙からの作成と、既存画像を背景にした注釈を同じ専用ダイアログで扱う。
- 初期機能は四角形、楕円、直線、矢印、吹き出し、テキスト。線の色・太さ、塗りつぶしの色・透明／不透明、移動、サイズ変更、削除、重なり順、元に戻す／やり直すを扱う。
- 背景画像の追加・移動・サイズ変更を扱う。自由描画・切り抜き・回転は初期範囲外。
- 通常の行ではその行の直後に挿入し、選択文章は保持する。既存画像や編集図では対象の画像記述を差し替える。同じ行に複数ある場合は右クリック位置で対象を特定する。
- 対象記述は Markdown 画像と HTML img の両方。OK で本文へ反映し Markdown プレビューを更新する。キャンセルでは反映しない。変更後のキャンセル・閉じるには破棄確認を出す。
- Delete で選択要素を削除し、Ctrl+Z / Ctrl+Y で元に戻す／やり直す。
- 同じ図が複数箇所で参照されていても、編集結果はその箇所のみ更新する。別の図として保存し、対象の参照だけ更新する。
- 背景画像の原本は保持し、各 SVG から共有画像を参照する。図の複製や再編集のたびに画像ファイルをコピーして容量を増やさない。
- 背景画像はローカル画像のみ。Web 上の画像は対象外。文書画像フォルダ内の画像はそのまま共有し、別の場所の画像は初回取り込み時に保存し、その後は共有する。
- キャンバス初期寸法は白紙で 800×600、背景画像ありで画像の寸法。幅・高さを変更可能にし、編集画面では全体が収まる倍率から拡大・縮小できる。Markdown 上の表示幅とは別に扱う。
- 他のアプリで作られた一般の SVG は背景画像として扱う。図形・文字の個別再編集は、この機能で作った編集図に限定する。
- 未保存文書は先に保存を求め、保存成功後に図編集を開く。保存をキャンセルした場合は本文・資産を変更しない。
- 図の保存失敗時は編集画面と編集内容を保持して再試行可能にし、本文の参照は差し替えない。
- 既存図を変更せず OK を押しても新しい SVG は作らない。白紙のまま OK を押しても挿入しない。
- 保存 SVG は共有背景画像への相対参照を維持する。WasabiPad の表示時にのみ画像込みの SVG をメモリ内で生成し、画像を重複したファイルとして永続化しない。
- 初期版は WasabiPad での表示・再編集を優先する。他の Markdown アプリでは背景画像が表示されない場合がある。画像込みの書き出しは初期範囲外。
- 共有背景画像ファイル自体の変更は全参照図に反映する。注釈の編集はその箇所のみ更新する。
- 背景画像の欠落・読み込み失敗は図形と説明文を保持したまま通知し、背景画像を選び直せるようにする。
- 図と取り込んだ背景画像は既存の文書画像フォルダにまとめる。WasabiPad 内の文書移動・名前変更は既存資産管理と同様に追従し、外部への持ち運びは文書と画像フォルダをセットで行う。
- 背景に取り込む一般 SVG は単独で表示可能なものに限定する。外部画像・フォント等の依存がある場合は理由を表示して取り込みを止める。この機能の編集図は背景取り込みではなく再編集で開く。
- Markdown 表示幅は既存画像の編集時に保持し、新規作成時は既存画像挿入の幅ルールを使う。キャンバス寸法・ズームとは分離する。
- 画像記述の外を右クリックした場合は白紙から作成する。画像記述上で対象を安全に特定できない場合は理由を表示して開始しない。複数行の img 記述も対象にする。
- 単一要素選択を基本とし、ドラッグで図形作成、選択後に移動・サイズ変更を行う。文字と吹き出し本文はダブルクリックで編集し、改行・文字色・文字サイズを変更可能にする。複数選択・グループ化・自動整列は初期範囲外。
- 編集開始時の文書と対象を記録し、元文書の外部更新等で対象が変わった場合は差し替えを止める。編集内容を保持して通知し、別の箇所や別の文書へ反映しない。
- 図の挿入・差し替えは本文の undo/redo の対象にする。本文または undo/redo 履歴から参照される SVG と共有背景画像を保持し、双方で不要になった段階で掃除する。
- 対象文書は既存画像貼り付けと同じ編集可能文書。拡張子だけで限定せず Markdown プレビューで表示する。読み取り専用文書では編集できない。
- 変更を OK で反映したら既存画像貼り付けと同様に Markdown プレビューを開く。開いている場合は配置を維持して更新する。キャンセル・変更なしの OK では表示状態を変えない。

## 実装方針

- 保存 SVG を編集図の正とする。内部エディタが生成する許可要素・属性のみを検証して編集モデルに読み込み、保存時に再生成する。別の JSON ファイルを独立した正として持たない。
- 任意 SVG の生 DOM を Markdown 本文へ挿入せず、既存の HTML サニタイズと CSP を緩めない。表示専用 SVG はメモリ内でのみ生成し、不要になった資源を解放する。
- 保存画像は既存画像資産経路を利用し、同じ背景内容の取り込みを再利用する。SVG の共有背景依存を掃除対象の参照追跡へ追加する。
- 本文と履歴に必要な資産を掃除から保護する。保存失敗・キャンセル・対象変更時は本文を更新せず、未反映の一時資産を残さない。
- 右クリック、本文更新、画像保存、プレビュー更新は既存経路を優先する。
- ユーザーの「合意」で実装を開始した。

## BDD と検証範囲

各仕様を対応する Given / When / Then シナリオで検証する。

- 通常行・選択文章からの新規挿入位置と本文保持。
- Markdown 画像、単一行／複数行 HTML img、同一行の複数画像の対象検出。特定できない記述は無変更。
- 各図形・吹き出し・テキストの作成、属性変更、移動、サイズ変更、重なり順、削除、undo/redo、改行。
- 保存 SVG の再編集往復で注釈と背景参照を保持。一般 SVG は背景として扱い、外部依存は拒否。
- 同じ図の複数参照で編集した箇所のみ更新。背景画像のファイル数・保存量が図の複製や再編集で増えない。
- 保存 SVG は共有参照を保ち、Markdown プレビューでは背景と注釈の両方を表示する。生 SVG の安全境界を保つ。
- 変更なし・白紙 OK、キャンセル・破棄確認、未保存文書の保存キャンセル、保存失敗と再試行。
- 背景欠落・読み込み失敗と再選択。共有背景変更は全参照図へ反映。
- 対象の外部変更や文書切替で誤反映しない。
- 文書移動・名前変更に SVG と背景参照が追従。
- 本文 undo/redo、参照削除、共有背景依存の掃除で必要資産を失わない。
- 新規／既存表示幅と、OK 後のプレビュー配置・更新。キャンセルと変更なしは表示状態を維持。

実装時は対象シナリオを先に追加して失敗を確認し、実装後に対象テスト、全体テスト、TypeScript 型検査、差分検査を実施する。ダイアログ操作と Markdown 表示はブラウザ検証に加え、実 Tauri の画像資産・保存・移動・undo の動作確認を区別して報告する。

## 既存実装の調査結果

- Markdown 本文の生 SVG は既存サニタイズで除去される。
- 通常の img 要素で SVG を表示する場合、SVG 内の外部画像参照は制限される。共有背景を参照する保存 SVG をそのまま表示するだけでは成立しない。
- 未使用画像掃除は本文中の画像参照のみを追跡し、SVG 内の背景参照を追跡しない。背景依存を認識する拡張が必要。
- 保存 SVG の共有参照を維持し、表示時にのみ背景を含む SVG をメモリ内で合成する方式を実装。一般 SVG は外部依存を拒否する。他アプリでの背景付き表示は保証しない。

## 使い方と確認状況

エディタ上の行または画像記述を右クリックし「図を編集」を選ぶ。図形をドラッグして配置し、選択した要素の色・太さ・文字などを変更する。「画像を追加」で背景を取り込み、「背景を選び直す」で欠落した背景も置き換えられる。OK で対象箇所に SVG の参照を反映し、Markdown プレビューを更新する。

仕様・規約の二軸レビューで指摘された資産保持、別フォルダの背景取り込み、アーカイブ参照、空白クリック、引用符なし HTML の解析を修正し、回帰テストを追加した。画面自動操作はブラウザの現在 URL を確認できず Computer Use が停止したため、実画面・実 Tauri の操作確認は残っている。
