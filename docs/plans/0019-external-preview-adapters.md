# 外部プレビューアダプタ実装計画

> この計画は[共通外部アドイン計画](0020-common-external-addins.md)に統合した。以下は旧方針の履歴。

## 目的

拡張子ごとのプレビュー処理をWasabiPad本体へ追加するのではなく、利用者が用意した外部プログラムを起動し、その生成物を既存のプレビュー領域へ表示する。ABC／LilyPondを最初の移行対象とし、本体の形式固有コードと配布サイズを減らす。

## 対象外

- Markdownのソース位置同期
- CSVの区切り文字変更・エディタ連動
- SQLiteのテーブル選択・ページング・対話型表示
- 登録コマンドとの設定・実行結果の統合
- 外部プログラムの自動ダウンロード、更新、恒久資産の削除
- 外部HTMLとWasabiPad間の双方向通信

## 用語と責務

| 概念 | WasabiPad | 外部アドイン |
| --- | --- | --- |
| ルール | 拡張子、実行ファイル、引数、表示形式を保存・選択 | - |
| 入力 | 保存済み通常ファイルのパスを`{file}`で渡す | 入力を解釈する |
| 出力 | 実行ごとの一意な`{output}`を渡し、現在世代だけ表示する | HTML/SVGと付属資産を生成する |
| 恒久資産 | 管理・解釈・削除しない | 音源、再生ライブラリ、CSS、JS等を管理する |
| 実行用一時フォルダ | 作成、世代管理、終了後の掃除 | その中へ必要な小さい生成物を書く |
| HTML | trusted external HTMLとして専用経路で表示する | 再生UIと資産参照を用意する |

## 実行契約

- 設定は拡張子一覧、実行ファイル、引数テンプレート、出力形式（HTML／SVG）で構成する。表示名・有効無効スイッチはMVPに追加しない。
- 拡張子はドットを除いて小文字化し、1つの外部アダプタ内で重複を許さない。外部アダプタ同士の同一拡張子も1件だけ許可する。
- 実行ファイルは絶対パスまたはPATH上のコマンド名を対象にする。相対実行ファイル、任意のcwd、シェル経由の実行はMVP対象外とする。
- 引数テンプレートでは`{file}`と`{output}`だけを扱う。置換値はWindowsの1引数として安全にエスケープし、利用者の手動引用符に依存しない。
- 対象は保存済みの通常ファイルだけとする。未保存文書、フォルダ、仮想項目、アーカイブ項目は実行しない。
- 起動契機は対象文書のプレビュー開始または明示的な再実行とする。ツリー選択だけでは実行しない。保存ごとの自動再実行もしない。
- 既存形式を既定で優先し、設定で外部優先を明示した場合だけ外部アダプタへ切り替える。
- 外部プログラムの終了成功、出力ファイルの存在、出力形式を確認してから表示する。終了コード、タイムアウト、上限超過、出力不足はプレビュー内の短い診断と再実行へ変換する。

## 実行状態

```text
未実行
  -> 実行中
  -> 出力待ち
  -> 表示中
  -> 終了・掃除

実行中/出力待ち -> 取消・文書切替・再実行 -> 終了・掃除
実行中/出力待ち -> 失敗 -> 診断表示 -> 再実行
```

各実行に世代IDを持たせる。終了通知・出力読み込み完了の両方で現在世代を確認し、古い実行結果を表示しない。新しい実行が古い出力を上書きしないよう、実行ごとに異なる出力先を使う。

## 出力とHTML表示

- `{output}`は外部プログラムが完成させる入口HTMLまたはSVGの絶対パスとする。
- HTMLは`srcdoc`へ文字列コピーせず、入口ファイルを基準に付属資産を参照できるfile-backed経路で表示する。相対パスの意味をWasabiPadが書き換えない。
- 外部HTMLはtrusted external HTML modeとする。JavaScript、`file://`、絶対パス、外部リソースを許可する。ただし親DOM操作とTauri IPCは許可しない。
- 通常のHTML文書は現在のスクリプト禁止`srcdoc`経路を維持する。
- 外部HTMLの動的表示は、実機でJavaScript/MIDI再生、親DOM遮断、Tauri IPC遮断、必要な資産参照を確認できるまで有効化しない。確認できなければ静的HTMLを含めて外部HTML表示を失敗扱いにする。
- WasabiPadは外部資産の名前・構成・不足理由を解釈しない。外部プログラムが自身の資産を用意できない場合は、外部プログラムの終了結果または出力不備として表示する。

## 一時成果物の掃除

- WasabiPadが作成した実行用一時フォルダだけをWasabiPadが所有する。
- プレビュー切替、取消、タブ閉鎖、終了した古い世代では、参照が不要になった実行用フォルダを削除する。
- 異常終了で残った専用フォルダは次回起動時に回収する。恒久的な外部アドイン資産や外部アドイン所有の出力領域は削除しない。
- 外部アドインが保持する大きな音源・再生ライブラリの容量や保持期間は、外部アドイン側の責務とする。

## 実装段階

### 1. 設定と判定

- 現在の`CONTEXT.md`、`ui/settings.ts`、`ui/settings-panel.ts`の設定保存パターンを再利用する。
- 外部アダプタの型、正規化、拡張子一致、既存形式との優先順位を追加する。
- 設定UIは既存の「アドイン」領域に外部プレビューアダプタの一覧を追加し、公式カタログと分ける。
- BDDを先に追加する。

### 2. 外部プロセス実行

- `src-tauri/src/lilypond_runner.rs`の終了待ち、取消、ジョブ領域、上限設計を再利用できるか確認する。
- 登録コマンドの即時実行経路（`ui/registered-commands.ts`、`src-tauri/src/commands/system.rs`）とは分離する。
- IPCを追加する場合は`shared/protocol.json`等の正本を変更し、生成物を同期する。`ui/generated`は手編集しない。
- `{file}`、`{output}`のWindows引数エスケープ、終了コード、タイムアウト、出力上限をテストする。

### 3. HTML/SVGのfile-backed表示

- `ui/viewer-html.ts`の現行`srcdoc`経路を直接緩和せず、外部HTML専用の表示経路を追加する。
- `ui/viewer-image-source.ts`、`ui/inline-preview.ts`、`ui/viewer.ts`、`src-tauri/src/viewer.rs`の責務を確認し、HTML/SVGの既存表示を再利用する。
- 実機で相対資産、絶対パス、JavaScript、MIDI、AudioWorkletの挙動を確認する。
- `src-tauri/tauri.conf.json`、capability、WebViewの権限を確認し、親DOMとTauri IPCが遮断されることを実証する。

### 4. 世代・取消・掃除

- 実行IDを作成し、文書切替・再実行・取消で旧処理を無効化する。
- 旧終了通知や旧HTML読み込み完了を表示へ反映しない。
- 参照終了後の実行用フォルダ削除と、異常終了後の起動時回収を実装する。

### 5. ABC/LilyPond移行

- 利用者が用意したABC/LilyPond外部ツールで、入口HTML/SVGを生成する設定例を作る。
- HTMLに埋め込まれた、または外部資産を参照するMIDI再生を実機で確認する。
- 表示、MIDI再生、取消、古い結果の破棄、実行用フォルダ掃除が確認できるまで、既存の`addins/abc`、`addins/lilypond`、公式アドイン管理、形式専用経路を削除しない。
- 受け入れ後に旧コードと公式アドイン管理を削除し、exe・インストーラサイズを移行前後で測定する。

### 6. SQLiteは別段階

SQLiteの読み取り、テーブル選択、ページング、状態保持は外部プレビューアダプタの静的出力契約に含めない。外部化は別計画として、機能再現度・配布量・exe削減量を比較してから判断する。

## BDDシナリオ

### 拡張子一致

**Feature:** 外部プレビューアダプタの選択

**Scenario:** 大文字拡張子を正規化して一致させる

**Given** `ABC`を対象拡張子に登録した外部アダプタがある
**When** `score.abc`をプレビューする
**Then** 外部アダプタが選択される

### 対象境界

**Feature:** 外部プレビューの対象ファイル

**Scenario:** 未保存文書と仮想項目を実行しない

**Given** 拡張子に一致する外部アダプタがある
**When** 未保存文書またはアーカイブ内項目をプレビューする
**Then** 外部プロセスを起動せず、既存の対象外表示を維持する

### 引数と出力

**Feature:** 外部プログラムへの受け渡し

**Scenario:** 空白を含む入力パスを1引数として渡す

**Given** 入力ファイルのパスに空白がある
**When** `{file}`と一意な`{output}`を置換して実行する
**Then** 外部プログラムは入力を1ファイルとして受け取り、入口HTML/SVGを出力する

### 世代管理

**Feature:** 外部結果の競合防止

**Scenario:** 古い実行が新しい表示を上書きしない

**Given** 同じ文書で外部実行Aの後に実行Bを開始する
**When** Aの終了通知がBより後に届く
**Then** Aの結果は表示せず、Bの結果だけを表示する

### 失敗

**Feature:** 外部実行の失敗表示

**Scenario:** 出力がない場合に再実行を案内する

**Given** 外部プログラムが成功終了したが`{output}`を作らない
**When** WasabiPadが結果を確定する
**Then** 出力不備の診断と再実行操作を表示する

### 掃除

**Feature:** 実行用一時フォルダの掃除

**Scenario:** 古い実行用フォルダを残さない

**Given** 外部プレビューを再実行または文書切替する
**When** 古い世代の表示が不要になる
**Then** WasabiPadが所有する古い実行用一時フォルダを削除する

### 既存形式との競合

**Feature:** プレビュー形式の優先順位

**Scenario:** 外部優先を指定しない場合は標準プレビューを使う

**Given** 拡張子が標準形式と外部アダプタの両方に一致する
**When** 外部優先が指定されていない
**Then** 標準プレビューを表示する

### Trusted HTML

**Feature:** 外部HTMLの信頼済み表示

**Scenario:** MIDI再生HTMLを専用経路で表示する

**Given** 外部アダプタが入口HTMLと再生資産を生成する
**When** 実行が成功する
**Then** JavaScriptと資産参照を許した外部HTML経路で表示し、親DOMとTauri IPCは利用できない

このシナリオは単体テストだけでは証明できない。Windowsの実WebViewで、発音・停止、親画面操作、Tauri IPC、資産参照、外部通信を確認する。

## 受け入れ条件とチェック

- `npm test`
- `npx tsc --noEmit`
- `npm run check:ipc`
- `npm run check:generated`
- `cargo test --workspace --locked`
- `git diff --check`
- Vite/Tauriビルド。実行中のGUIが`dist`をロックする場合は一時出力先を使う。
- Windows実機で外部ABC/LilyPondの表示、MIDI再生、取消、古い結果破棄、実行用一時フォルダ掃除、trusted HTMLの権限境界を確認する。
- 旧コード削除前後のexe・インストーラサイズを比較する。

## 未確認事項

- Tauriの現行capability設定で、専用file-backed WebViewから親DOM・Tauri IPCを確実に遮断できるか。
- `file://`、絶対パス、外部リソース、AudioWorklet、MIDI再生の実WebView挙動。
- ABC/LilyPondの利用者が選ぶ具体的な外部ツールと引数。
- Windowsの外部プロセス取消が子プロセスまで確実に届くか。
- 外部アドインが管理する恒久資産の容量・保持期間。
