# ファイルツリーの軽量な日時表示と更新

本計画は 0028 のフォルダ集計に関する仕様を置き換える。

- フォルダの更新日時は OS が記録するフォルダ自身の日時を表示し、配下を走査しない。フォルダのサイズは「—」とし、サイズの背景バーを表示しない。ファイルの日時・サイズと相対バーは維持する。
- 配下全体のサイズ・更新日時を自動で再帰集計しない。必要なフォルダサイズはエクスプローラーのプロパティで確認する。
- 更新日時は秒を表示せず、日付を列の左端、時刻を右端に配置する。日時列の幅は現在と同程度とする。日時とサイズの列間余白と、背景バーの濃さはそれぞれ現在の約半分とする。
- 3秒ごとの一覧更新は維持する。変化がない場合は表示を維持し、変化がある場合も選択、スクロール位置、展開状態、名前変更中の入力をできるだけ維持する。不要なメタデータの再取得を避ける。
