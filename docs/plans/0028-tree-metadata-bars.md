# ファイルツリーの日時・サイズ表示

- 同じ親の表示中のファイルとフォルダを比較し、日時・サイズの各列に淡い背景バーを表示する。サイズは最大値に比例し、日時は最古を最長、最新を最短とする。
- 日時がすべて同じ場合は全項目を最長とし、サイズがすべて 0 の場合はバーを表示しない。日時は秒を表示せず、比較には元の精度を使う。
- 一覧を先に表示し、ファイル情報、フォルダの集計結果の順に取得できたものから表示する。取得済みの兄弟項目でバーを計算し、取得に応じて更新する。
- フォルダは既存の集計日時・集計サイズを表示する。集計中は「集計中…」、取得が不完全な場合は「一部取得不可」とし、バーを表示しない。リンクのサイズは比較しない。
- 表示中に取得済みの結果を再利用し、一覧の再読み込み時は再取得する。大きい単一フォルダの集計時間は保証しない。
