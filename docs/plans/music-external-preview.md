# ABC・LilyPond 外部プレビュー

2026-10-03: ソース・旧資材・専用テストは別プロジェクトへ分離した。以下は移植時点の記録。現在の境界は[ADR-0023](../adr/0023-external-music-project.md)を参照。

## 合意済み（2026-09-30）

- `addins/pending` の ABC・LilyPond 資産を、ADR-0022 の共通外部プレビュー方式へ移植する。
- 両形式で譜面表示と音声再生を提供する。
- 利用者が手動配置し、既存の外部プレビュー設定に登録する。導入手順・設定例・サンプルを用意する。
- 旧音楽アドイン管理・専用実行経路は復活させない。
- Node.js を別途導入し、LilyPond 用には変換プログラムも別途導入する。保存済みの `{file}` から `{output}` の HTML を生成する。
- 通常使用中はオフラインとする。JavaScript は配置用にビルドし、再生用音源は利用者がローカル配置する。
- LilyPond が MIDI を生成しない場合はソースを自動改変せず、譜面表示を保ち、再生不可の理由と `\midi {}` の案内を表示する。
- 複数ページ・複数曲を保持し、曲選択・再生・停止を提供する。
- 利用者がローカル配置した共通の SF2/SF3 音源を CLI 引数で指定する。
- ABC は abcjs で MIDI を生成し、LilyPond は変換プログラムの MIDI を使う。既存依存の spessasynth_core で WAV を生成し、HTML の標準音声プレーヤーで再生する。
- 外部 HTML の隔離を保ち、旧独自 URL・音源 fetch・AudioWorklet に依存しない。
- 生成時間・容量・ファイル数の独自制限は設けない。共通 runner の 30 秒・64 MiB・256 ファイルの制限も撤廃する。取消、入力検証、出力の一時領域内確認、所有者を確認した清掃は維持する。

## 合意した検証境界

- CLI 入力から HTML と必要資産の生成。空白・日本語パス、依存不足・変換失敗も対象とする。
- 生成 HTML の全譜面表示、曲選択、再生・停止。
- 音源不足時も譜面を保持し、再生不可の理由を表示する。
- 通常使用中に外部通信を行わない。
- 実機 WebView の表示・発音と親 DOM・IPC の隔離は、自動テストと区別して確認する。

## 実装・検証

- LilyPond 実行パスは引数指定でき、未指定時は PATH から検索する。相対 include は入力元の親ディレクトリから解決する。
- 実機検証は安全な隔離環境で行い、自動テストの結果と区別する。

## 検証記録（2026-10-01）

- LilyPond 2.26.0 の実 CLI で日本語・空白・Windows extended パス、相対 include、2 book・4ページ・2曲、MIDI なし、構文エラーを確認した。入力ソースは変更されない。
- サンプル SF2 とローカル SF3 から、無音ではない WAV を生成した。音源不足時も譜面が表示され、再生不可の理由が出る。
- SVG と MIDI は新規出力ファイルの生成時刻順に保持する。時刻が同じ場合だけ更新時刻・ファイル名を使う。粗い時刻精度のファイルシステムでは厳密なソース順を保証しない。ページと曲の対応を推測しない。
- 専用 APPDATA・TEMP・WebView2 profile で本番 runner と外部 HTML 表示関数を使用した。ABC の全2曲、LilyPond の全4ページ・2曲を実 WebView2 上で確認した。SVG の表示領域とページ画像の読み込みを確認し、画面も目視確認した。
- 両形式の WAV は asset URL から HTTP 206 で読み込まれ、再生位置が進み、停止で pause と先頭復帰を確認した。これは実機の再生動作確認であり、スピーカーの音を聴取した確認ではない。
- 親 DOM へのアクセスは SecurityError。生成 HTML の CSP は IPC 通信を許可しない。CSP を付けない検証用 HTML でも同じ sandbox で IPC が「Origin header is not a valid URL」と拒否された。
- 旧64 MiB・256ファイル超過後の生成成功、31秒の生成成功、明示的取消と所有する一時領域の清掃を公開 runner 境界で確認した。
- 全体検証: npm test 103ファイル・1090件成功（既存todo 2件）、Rust workspace 259件成功、UIとABC表示処理の型チェック、差分の空白チェック成功。
