# MOV・MP4の動画プレビュー

## 状態

2026-10-03：直接再生方式とQ1〜Q7への合意に基づき実装済み。規約・仕様レビューの指摘を解消。

## 合意済み仕様

- 既存WebViewでローカルMOV・MP4を直接再生する。
- 対応する映像・音声形式のみ再生できる。全MOVの再生は保証しない。
- 自動再生はしない。標準の再生・一時停止・シーク・音量操作を使う。
- 全画面表示は既存のプレビュー操作に合わせる。
- 非対応の場合は「この動画の形式は、この環境では再生できません」と表示する。
- 自動変換や追加ソフトの導入は行わない。
- 配置変更では再生位置と再生状態を維持する。
- 別ファイルへの切替と閉じる操作では停止する。開き直したら先頭から。

## 合意済み境界条件

- 初期対応は通常の実ファイルのみ。ZIP・7z内の動画は対象外。
- 読み取り失敗と判断できる場合は「動画を読み込めません」と表示する。
- 形式非対応と判断できる場合は合意済みの非対応文言を表示する。
- 破損など、原因を判断できない再生失敗は「動画を再生できません」と表示する。原因を断定しない。
- WebViewのMediaError 4は形式非対応だけでなく読み取り失敗・破損も含み得るため、原因不明として扱い、考えられる原因を補足する。形式非対応を断定するための全量読込や独自解析は追加しない。
- 更新は先頭に戻して停止する。
- 別タブへの切替でも停止する。戻ったら先頭から。
- 画面幅による一時退避では一時停止し、再生位置を保持する。再表示後は手動で再開する。

## BDD受入条件

- Given 通常のMOV・MP4、When プレビュー形式を自動判定する、Then 動画プレビューとして扱う。拡張子の大文字・小文字を区別しない。
- Given 動画プレビューを開いた、When 読み込みが完了する、Then 自動再生せず標準操作を利用できる。
- Given 再生中の動画、When 配置を右・上・下へ変更する、Then 再生位置・再生状態を維持する。
- Given 再生中の動画、When 別ファイル・別タブへの切替または閉じる操作を行う、Then 音声を含め再生が停止し、再表示は先頭から停止状態になる。
- Given 動画プレビュー、When 更新する、Then 先頭へ戻り停止する。
- Given 再生中の動画、When 画面幅による一時退避が発生する、Then 一時停止し位置を保持する。再表示しても自動再開しない。
- Given 読み取り失敗・形式非対応・原因不明の再生失敗、When エラーを検知する、Then 判別可能な範囲で対応する文言を表示する。
- Given ZIP・7z内の動画、When プレビューを判定する、Then 今回の動画再生対象にはしない。
- Given 動画プレビュー、When 全画面表示を切り替える、Then 既存のプレビュー全画面操作を利用できる。

## 実装・検証の方針

- 既存の形式判定、ローカルファイル配信、プレビュー操作と破棄経路を再利用する。
- 閉じる操作が単なる非表示でも再生を停止させる。別ファイル・別タブ・一時退避を共通の状態遷移経路で扱う。
- 動画全体を画像用のメモリ展開・キャッシュ経路へ渡さず、通常実ファイルの配信経路を利用する。
- デコーダの追加容量は0MB。実装による容量増は配布ビルドで測定する。
- BDDでは上記の受入条件を確認してから実装する。
- 実機ではMOV・MP4の再生、音声、シーク、配置変更、全画面とエラーを確認する。
- 自動検証とTauri実機の再生確認を区別する。
- 非対応コーデックの代表MOVと、対応するMOV・MP4を用いた実機検証を行う。実ファイルを用意できない項目は未確認として報告する。
- 可逆な通常プレビュー拡張のため、現時点ではADRは作らない。

## 検証結果

- UI全体：104ファイル・1,116テスト成功。型チェック、IPC契約チェック、配布用UIビルド成功。
- Rust core全体：227テスト成功。動画の本文を読み込まず、メタデータのみで開く経路を検証。
- 形式判定、アーカイブ除外、更新・閉じる・切替時の停止、一時退避、全画面の状態維持を自動検証。次のプレビュー生成待ちでも旧動画を直ちに停止する。
- ブラウザー上で、合成したH.264/AACのMP4を実コンポーネントで読み込み・再生確認。初期停止、再生開始、MediaErrorなしを確認。
- Tauri実機でのMOV・MP4再生、音声・シーク操作、および非対応コーデックの代表MOVは未確認。
- UI配布成果物は1,077,517 bytesから1,080,633 bytesへ増加（+3,116 bytes、約3.0 KiB）。追加デコーダ・依存ライブラリなし。インストーラー容量の差ではない。
