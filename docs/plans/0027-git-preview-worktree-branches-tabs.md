# Gitプレビュー: 未コミット・ブランチ選択・新規タブ

状態: 合意済み。実装・自動検証・レビュー完了。

## 要望

- 上段のブランチ名の上に「未コミット」を置き、展開すると変更ファイルを表示する。
- ブランチ名を押して一覧から選べるようにする。
- コミット内の変更ファイルを右クリックし「新規タブで開く」で表示する。
- 共通プレビュー画面のタイトル部分の左端に「標準プレビュー」または「外部プレビュー」を表示する。

## 合意: 共通タイトルの種別表示

- 標準プレビューか外部プレビューかを、現在実際に表示している方式から判定する。配布元で区別しない。
- 種別はタイトル部分の左端に常時表示するクリック操作のない文字ラベルとし、既存のタイトル・形式表示・更新・全画面・閉じるを維持する。外部プレビューの生成中と失敗時も「外部プレビュー」と表示する。
- Git以外にも共通で適用する。

## 合意した判断

1. ブランチ選択は履歴の閲覧対象だけを切り替える。作業ブランチと作業ファイルを変更しない。
2. 未コミット一覧はステージ済み・未ステージ・未追跡を含め、無視対象を除外する。差分はHEADと現在の保存済み内容を比較し、WasabiPad内の未保存編集を含めない。
3. コミット内ファイルの「新規タブで開く」は現在の作業ファイルを開く。選択コミット時点の内容は開かない。

## 例外・操作

4. 未コミット欄は常に現在の作業ブランチを対象とし、横に作業ブランチ名を表示する。閲覧ブランチを切り替えても対象を変えない。
5. ブランチ一覧はローカルと取得済みリモートを区別して表示し、自動取得しない。切替後は最新コミットを展開し最初の変更ファイルを選択する。
6. 新規タブは行に表示されたパスの現在の作業ファイルを通常の編集可能なタブとして開く。存在しなければ理由を表示し、履歴内容への代替や改名先の推測はしない。未コミット欄にも同じ右クリック操作を設ける。
7. 初期表示は変更があれば未コミットを展開して最初のファイルを選択し、なければ最新コミットを選択する。既存の更新ボタンで再取得し、残っている選択を保持する。
8. 競合ファイルを「競合」と明記して一覧に含め、HEADとの差分と保存済み競合マーカーを表示する。競合解消操作は追加しない。

## 表示・状態の境界

9. HEADと現在の保存済み内容に差分のないファイルは未コミット一覧から除外する。ステージ済み・未ステージの変更が相殺された場合も表示しない。
10. ブランチ一覧は検索可能とし、クリック・Enterで確定、Escで閉じる。detached HEADは現在位置として表示する。更新時に閲覧ブランチが消失したら理由を示して現在の作業HEADへ戻す。
11. Gitプレビューの閲覧ブランチ・展開・選択・スクロールは保存せず、タブ復帰時も再起動後も復元しない。現在の作業HEADを対象とする初期表示から始める。上下分割比率だけは既存の画面寸法設定として保存を続ける。他形式のプレビューの保持方針は今回変更しない。
    タブ内には対象リポジトリのパスだけを保持し、復帰時に同じ対象の初期表示を開く。このパスは再起動用の保存には含めない。
12. 新規タブの重複・表示形式は既存操作に合わせ、開いたタブへ移動する。未コミット差分も1MiBまたは2万行で明示的に省略し、バイナリは変更情報のみ。未追跡テキストは全行を追加として表示する。

## 既存仕様の継承

現行コードの復元方針を確認した。再起動後も保存するのはプレビュー配置・分割寸法・外部アダプター設定など。Git以外のプレビューの閲覧ブランチに相当する内部選択やスクロールをタブ単位で保存する仕組みはない。現行Gitだけがタブ内のworkspace snapshotで閲覧状態を保持しており、今回これを撤去する。再起動時のStoredTabにはどの形式のプレビュー内部状態も含まれない。

- ファイルツリーの `.git` ディレクトリとworktreeの `.git` ファイルを対象とし、本文と未保存編集を保持する。
- Gitプレビュー内の読み取りはリポジトリを書き換えず、自動取得・外部差分プログラム・textconvを実行しない。
- コミット差分の第1親比較、最初のコミット、固定HEADによる100件ずつの履歴追加を継承する。
- 選択・更新・閉じる・タブ切替後に古い読み取り結果を反映しない。更新中の旧一覧は操作不可とする。
- Git未導入・不正なリポジトリ・読取失敗は理由を表示する。
- 初コミット前の未コミット差分は空状態と比較する。未コミット変更なしは「変更なし」と表示する。
- リポジトリの変更ファイルから新規タブで開いた後は、既存の通常文書操作を利用する。

## 受入確認

- ステージ済み・未ステージ・未追跡・相殺・削除・名前変更・競合・初コミット前・バイナリ・上限超過の一覧と差分。
- ローカル／リモート／detached HEADの一覧、検索、確定・取消、閲覧切替と作業ブランチ不変、ブランチ消失時の更新。
- コミット行と未コミット行から現在のファイルを開き、未存在時の説明、既存タブ・表示形式の扱い。

- 遅い読取と連続選択・閉じる・タブ切替が重なっても古い表示へ戻らない。

### Revert後に同内容のファイルが残る問題の修正

Git読取の設定隔離でシステム・個人設定の `core.autocrlf` が無効になり、HEADがLF、保存ファイルがCRLFの環境で改行形式だけを未コミット変更として表示していた。通常Gitの `core.autocrlf` と `core.eol` だけを読み取り、隔離した作業ファイル比較へ適用する。外部差分・textconv・取得禁止は維持する。相殺判定と特殊差分にも同じ改行規則を適用した。

Revert、インデックスから除外したファイル、リポジトリ固有の属性、不正な設定値の回帰テストを追加し、失敗から成功への変化を確認した。core全体252テスト、型検査と空白検査が成功。実アプリでのRevert操作は未確認。
