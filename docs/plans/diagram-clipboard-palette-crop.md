# 図を編集：画像コピー・貼り付け、配色セット、画像部品のトリム

状態: 全体仕様の合意後に実装済み。規約・仕様レビューの指摘を修正済み。

## 画像コピー・貼り付け

- 外部アプリでコピーした画像を、図を編集画面で Ctrl+V により画像部品として追加する。
- 追加位置は作業領域の中央。縦横比を保ち、移動・拡大縮小・削除できる。
- 文字入力中は通常の文字コピー・貼り付けを優先する。
- 選択した画像部品は Ctrl+C / Ctrl+V で複製できる。複製は少しずらして置く。
- 貼り付け直後から表示する。貼り付け1回はUndo1回で取り消せる。
- OKで保存、図編集のキャンセルで追加を破棄する。既存の画像ファイルを壊さない。
- 読み込み失敗時はエラーを表示し、編集中の図を保持する。

## 配色セット

- 標準・赤・青・緑・黄・グレーの6種類を見本付きで用意する。
- セットは線色・塗り色・文字色の組み合わせ。選択中の図形と次に作る図形へ適用する。
- 透明な塗りもセットの塗り色に変える。既存の個別調整・透明設定は残す。
- 画像本体の色は変更しない。
- 選んだ配色は図編集画面を閉じるまで保持し、次回は標準に戻す。

## 画像部品のトリム

- 貼り付け画像と既存の「画像を追加」で配置した画像部品が対象。背景画像は対象外。
- 画像部品を選択して「トリム」を押し、枠のドラッグで残す範囲を決める。
- 「適用」で確定。「キャンセル」でトリム前に戻す。
- 元画像を保持し、再トリムで範囲を広げ直せる。「トリム解除」で全体表示に戻す。
- トリム確定はUndo1回で取り消せる。保存・再編集でも範囲を保持する。
- 非表示になった部分も元画像ファイルには残る。

## 互換性と操作の境界

- 従来の図にある、役割を記録していない画像は背景として保護する。新しく追加する画像部品からトリムできる。
- 図内コピーは同じ図編集画面の中での複製を対象とする。
- トリム中は背後の図編集操作を無効化し、適用・キャンセル後に復旧する。
- 画像部品も既存の文書画像資産として保存・参照・不要画像整理の対象にする。

## 検証する振る舞い

BDDで各仕様を検証する。既存の画像追加・保存・Undoの経路を再利用する。

1. Given 図編集が開いている / When 外部画像を貼り付ける / Then 即時表示され、UndoとRedoができる。
2. Given 文字を編集中 / When コピー・貼り付けする / Then 文字入力として処理する。
3. Given 画像部品を選択 / When コピーして貼り付ける / Then 少しずらした複製ができる。
4. Given 画像を追加済み / When OKまたはキャンセル / Then 保存または破棄され、既存資産は保持される。
5. Given 読み込めない画像 / When 貼り付ける / Then エラーを表示し、図と編集履歴は保持される。
6. Given 図形を選択 / When 配色セットを選ぶ / Then 線・塗り・文字色と次の作成色が更新される。
7. Given 配色を変更済み / When 図編集を開き直す / Then 標準に戻る。
8. Given 画像部品 / When トリムを適用・取消・解除 / Then 各表示範囲が反映され、元画像は保持される。
9. Given トリム済み画像 / When Undo・Redoまたは保存後の再編集 / Then 表示範囲を復元できる。
10. Given 既存の編集図 / When 新機能の追加後に開く / Then 従来どおり表示・編集・保存できる。
