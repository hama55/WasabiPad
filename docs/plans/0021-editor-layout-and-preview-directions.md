# エディタの寸法安定化とプレビュー配置

状態: 実装済み。自動検証完了。Tauri実画面の操作確認は未実施。

## 確定した要件

- 行番号領域は、行数の桁数とフォント設定が同じなら幅を一定にする。
- 検索文字列と置換文字列の入力欄を同じ幅にする。通常の1行配置でも、狭幅時の2行配置でも揃える。
- プレビュー配置は右側・上側・下側。上側と下側はエディタとの上下分割とする。
- 閉じているときに右端へマウスを寄せると、右上に上側用、右中央に右側用、右下に下側用の開くボタンを同時表示する。
- 表示中もエディタの右端へマウスを寄せると、現在配置以外の2つの方向ボタンを表示する。選択で配置を切り替える。
- 全配置・全画面とも、右端から「×で閉じる」「全画面」「外部プレビュー更新」の順に共通ツールバーへ並べる。更新は外部生成物の表示中だけ表示する。
- 全画面解除で元の配置へ戻す。全画面中はエディタがないため方向ボタンを表示しない。
- 初回の分割サイズは半分。境界のドラッグで調整できる。
- 右側の幅と上下の高さを別々に記憶し、上側・下側は高さを共有する。

## 追加で確定した要件

- 方向を指定しない入口の配置は設定画面のオプションで選べる。初期値は右固定。
- 配置・分割サイズはアプリ全体で記憶し、再起動後も引き継ぐ。
- 分割軸の表示領域が足りない場合、本文の最低寸法を守るためプレビューを一時退避する。領域が戻れば元の配置・分割サイズで復元する。
- 手動で閉じたプレビューは自動復元しない。

## 合意した詳細

- 方向未指定の設定の選択肢は「右固定」「上固定」「下固定」「最後に選んだ方向」の4つ。
- この設定の変更は次に方向未指定の入口から開くときに反映する。表示中の配置は移動しない。
- 方向指定ボタンはこの設定にかかわらず指定方向で開き、最後に選んだ方向を更新する。
- 上下分割の最低高さは本文・検索置換・プレビューの操作部を操作できる寸法にする。
- 分割サイズは利用可能な分割領域の割合で保存し、表示領域に合わせて最低寸法を確保する。
- 表示中の方向切り替えは同じプレビューを保持し、内容・閲覧位置を保つ。再生成・payload再送はしない。
- 上下配置の閉じるボタン用余白を廃止する。方向ボタンはエディタ領域を基準に配置する。

## 検証予定

- 同じ桁数内で行数・スクロール位置が変わっても行番号領域の幅が変わらない。
- 桁数・フォント設定の変更には必要な幅を反映する。
- 検索・置換入力欄の幅を通常配置・2行配置で比較する。
- 各方向の開閉、境界ドラッグ、全画面化と解除、狭い表示領域での状態遷移を確認する。
- 自動検証と実画面の確認を区別して報告する。
