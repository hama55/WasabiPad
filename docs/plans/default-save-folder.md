# ＋ボタンで作る新規タブのデフォルト保存先

## 状態

2026-10-24 に設計全体へ合意し、実装・自動検証・レビュー済み。

## 目的

最上部のタブバーの＋ボタンでメモを始める際、保存場所やファイル名を毎回考える負担を減らす。

## 確定した仕様

- 「起動時に開くパス」を廃止し、「デフォルトの保存フォルダ」に置き換える。旧設定値を新設定へ流用しない。
- 未指定時は Windows が管理するドキュメントフォルダを使う。固定の環境変数によるパス結合ではなく、既存 Tauri API の `documentDir()` を利用する。
- 新しい保存先指定と仮名の割り当ては、最上部タブバーの＋ボタンによる新規タブだけに適用する。他の新規タブ入口やファイルツリーの新規メモ操作は現状を維持する。
- ＋ボタンで作ったタブは、アクティブなフォルダにかかわらずデフォルトの保存フォルダを使う。
- 作成時に `memo.txt`、`memo1.txt`、`memo2.txt`…の既存命名規則で仮保存パスを決め、パス欄へ表示する。既存ファイル・同名フォルダ・同じウィンドウの他の未保存タブの候補との重複を避ける。Windows のパス比較規則に合わせ、大文字小文字の違いだけで別候補とは扱わない。
- 仮保存パスは保存済みパスと区別し、タブ作成時には実ファイルを作らない。
- 初回 Ctrl+S は仮保存パスを候補にした OS 保存ダイアログだけを開き、既存の名前・形式入力を重ねない。保存形式は既存の新規メモ既定値（UTF-8 / CRLF）。名前と保存先はダイアログで変更でき、保存成功後は実際の保存先を表示する。キャンセル・失敗時は未保存状態と本文、仮保存パスを保持する。
- 設定変更は以降に＋ボタンで作るタブへ適用し、既存の未保存タブの仮保存パスは変更しない。
- 設定先が使えない場合もメモの入力は可能にし、保存時に事情を表示して別の保存先を選べるようにする。設定を空欄にするとドキュメントを使う。
- 仮保存パスを表示したまま Enter を押しても開く処理を行わない。パス欄を書き換えて Enter を押した場合は従来の移動処理を使う。未保存文書から移動する際の既存の保存確認を維持する。
- 仮保存パスは「現在のファイルをお気に入りに追加」の対象にしない。その他の実ファイル向け処理にも保存済みパスとして渡さない。
- 別ウィンドウの未保存候補までは予約しない。別ウィンドウや外部アプリが同名ファイルを作った場合は、保存時の既存の上書き確認を維持する。
- 未保存本文を再起動時に復元しない現行仕様を維持する。＋由来の空タブが復元される場合は仮名を再選定する。

## 設計上の境界

- ＋ボタンと `newFile` コマンドは現在 `tabs.newBlank()` を共有している。＋の入口だけに新しい動作を接続し、コマンドの動作は変えない。
- 仮保存パスは実在する文書パスや `session.savePath` に設定せず、保存成功までは未保存文書として扱う。
- 新規タブの非同期作成が重なった場合も、同じウィンドウの候補確定を整合させる。空ファイルによる名前の予約はしない。
- 設定先の取得・参照に失敗しても、空タブ作成と本文入力を妨げない。別の場所へ無断で保存せず、保存時に場所を選べるようにする。

## 接続点

- `ui/settings.ts` / `ui/settings-panel.ts`: 旧設定の廃止、新設定の保存と表示。
- `ui/tab-view.ts` / `ui/main.ts` / `ui/tabs.ts`: ＋ボタン入口、初期フォルダ解決、タブごとの候補。
- `ui/document-controller.ts`: 未保存文書、パス欄表示、初回保存候補。
- `ui/addressbar.ts` / `ui/favbar.ts`: 仮保存パスと実在パスの意味の区別。
- `ui/stored-tabs.ts`: ＋由来の空タブと他の空タブを区別し、＋由来だけ復元時に仮名を再選定する。
- `core/src/filename.rs`: 既存の候補生成規則を再利用する。
- `ui/folder-actions.ts`: 旧起動パス設定の更新処理を撤去する。

## BDD受入条件

- Given 保存先未指定、When ＋を押す、Then ドキュメント内の仮保存パスを表示し、ファイルは未作成。
- Given カスタム保存先と既存の memo.txt、When ＋を押す、Then 既存規則に従って memo1.txt 以降の空き名を候補にする。
- Given 同じ保存先の未保存タブ、When ＋を連続で押す、Then 候補が重複しない。
- Given 別のフォルダを表示中、When ＋を押す、Then デフォルト保存先を使う。
- Given 他の新規タブ入口、When 新規作成する、Then 既存動作を維持する。
- Given 仮保存パスのある文書、When 初回保存をキャンセル、Then 本文と仮保存パスを維持しファイルは未作成。
- Given 保存成功、When 続けて保存、Then 実際の保存先へ通常保存する。
- Given 既存の未保存タブ、When 設定変更、Then 既存候補は維持し以降の＋で新設定を使う。
- Given 使えない設定先、When メモを書いて保存、Then 本文を保持して別の保存先を選べる。
- Given 旧起動パス設定、When 起動、Then 旧設定を自動オープンにも新保存先にも使用しない。
- Given ＋由来の未保存文書、When 初回 Ctrl+S、Then 仮保存パス入りの OS 保存ダイアログだけを開く。
- Given 仮保存パス表示、When 未編集のまま Enter、Then 未作成ファイルを開こうとしない。
- Given 仮保存パス表示、When 別のパスを入力して Enter、Then 既存の保存確認と移動処理を使う。
- Given 未保存の仮保存パス、When お気に入り追加の対象を取得、Then 実ファイルとして返さない。
- Given 仮名決定後に同名ファイルが外部で作成された、When 保存、Then 既存の上書き確認を省略しない。
- Given ＋由来の空タブ、When 再起動で復元、Then 本文は復元せず仮名を再選定する。
- Given ＋の仮名取得中、When 閉じた＋タブを復活、Then 両方のタブを保持し仮名を重複させない。
