# 行移動・プレビュー操作・検索ヘルプの整理

## 状態

2026-10-02：Q1〜Q6・補足条件・全体仕様に合意。実装済み。

## 合意済み仕様

### 行へ移動

- ステータスバーの現在行と総行数の表示を維持し、どちらからも同じダイアログを開く。
- 行番号入力と［先頭行］［最終行］ボタンを設ける。
- ボタンは即移動して閉じる。入力はEnterで移動して閉じる。
- 空・整数以外・1〜最終行の範囲外は移動せず、エラーを表示して開いたまま。
- 既存の onGoTo → editor.goTo(line, 0) を再利用する。

### プレビュー形式

- 現在形式の表示を押すと開くパネル。3列基本で候補増加時は行を追加する。
- 現在の6候補を既存順に表示する：Markdown、CSV、Image、PDF、html(静的)、SQLite。
- 選択中を強調。クリック／Enterで切り替えて閉じる。
- ホバーでは切り替えない。Esc／外側クリックは変更せず閉じる。
- 候補定義・利用可否・形式変更の共通経路を再利用し、利用不可候補は無効表示を維持する。
- 自動判定・外部プレビューの選択経路は維持する。

### CSV区切り文字

- プレビュー上部の直接操作select/inputを削除し、既存ダイアログを残す。
- ダイアログを開くボタン・コンテキストメニューと applyDelimiter の共通更新経路を維持する。
- 削除する入力要素に保持していた値は内部状態に移す。描画・親通知の参照も更新する。
- エディタ側ステータスバーの区切り文字操作は対象外。保存機構は追加しない。

## 合意済み補足条件

- 行番号は現在行を初期値として選択・フォーカスする。Esc／キャンセルは移動しない。
- 移動後は既存どおり対象行頭へキャレットを置き、中央表示してエディタへフォーカスする。
- 1行だけでも先頭／最終の両ボタンを表示する。行数は既存エディタに従う。
- 形式パネルはタイトルバーの切り取り領域外へ表示し、狭いペインでは列数を減らす。
- Tabで候補へ移動、Spaceでも選択可能。閉じると形式表示へフォーカスを戻す。
- 別ウィンドウで形式選択を非表示にする既存条件を維持する。
- 狭いアプリ内プレビューではCSV操作をアイコン表示にして、形式選択・全画面・閉じるの入口を確保する。

## BDD受入条件

- Given 現在行／総行数表示、When どちらかを押す、Then 同じダイアログが開く。
- Given 行移動ダイアログ、When 先頭／最終または有効な入力を確定、Then 対象行頭へ移動して閉じる。
- Given 行移動ダイアログ、When 不正入力を確定、Then エラーを表示し移動せず開いたまま。
- Given 行移動ダイアログ、When キャンセル、Then キャレット位置は変わらない。
- Given 形式パネル、When 有効候補をクリック／キーボードで確定、Then 共通経路で切り替えて閉じる。
- Given 形式パネル、When ホバー／Esc／外側クリック、Then 形式を変更しない。
- Given 利用不可候補、When パネルを開く、Then 無効表示で選択できない。
- Given 狭いペイン、When パネルを開く、Then 候補が切れず操作できる。
- Given CSVプレビュー、When ダイアログで区切り文字を変更、Then 再描画され、上部に直接入力欄はない。
- Given CSV区切り文字ダイアログ、When 空値を確定／Esc、Then 既存の拒否／キャンセル動作を維持する。
