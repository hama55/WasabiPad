# 外部プレビューからの元ソース位置移動

状態: 合意済み。

## 共通仕様

外部プレビューの共通契約に、入力元文書内の位置へキャレット移動を要求する機能を追加する。楽譜プレビューはこの契約の利用側となる。

- 対象は、そのプレビューの入力元文書だけ。別ファイルは開かない。
- 本体が入力元文書・プレビューの表示時点・要求位置の有効性を検証してから移動する。
- 移動先をエディタの画面内に表示する。フォーカスはプレビュー側に残す。
- 元ソース編集でプレビューが古い場合や、位置を特定できない場合はキャレットを移動せず、理由を短く表示する。
- 既存の外部プレビューの隔離を維持する。位置移動機能を使用しない既存プレビューの表示を維持する。

## 楽譜側の仕様

- ABC・LilyPond・MusicXML、通常表示・練習モードを対象とする。
- 音符・休符クリックで元ソースの対応記述先頭へ移動する。
- 和音はクリックした構成音の先頭。個別識別できない場合は和音全体の先頭。
- 繰り返しの再生順に関係なく、クリックした譜面上の記述へ移動する。
- タイの後続音は、後続音自身の記述先頭へ移動する。
- MusicXMLでは元XMLの対応する <note> 開始タグへ移動し、変換後のLilyPond位置は移動先にしない。
- 既存のクリック再生・シーク・練習操作を維持する。

## 責任分担

- 外部プレビュー共通契約: 位置移動要求と結果の通知。
- WasabiPad本体: 要求元と対象文書・表示時点・位置の検証、キャレット移動、スクロール。
- 楽譜プレビュー: 譜面上の対象から元ソースの対応位置への変換、既存クリック動作との併用。

## 検証範囲

共通契約の入力検証と文書・表示時点の対応、3形式の元ソース対応、和音・休符・タイ・繰り返し、練習モード、フォーカスとスクロール、従来プレビューの互換性を検証する。実際のTauri/WebView2操作確認は自動テストの結果と区別して報告する。

## 設計上の必須条件

- 入力元はパスだけでなく文書識別と表示時点のスナップショットに結び付ける。
- 古い子iframeからの要求へ、現在の表示IDを付け直して有効化しない。
- 外部HTMLの隔離を緩めず、現在の出力iframeの送信元だけを限定的に受け付ける。既存の親・本体間の送信元検証を維持する。
- MusicXMLの位置は変換時に元の <note> と対応付け、音高や再生時刻の推測で決めない。
- 現行の楽譜クリック処理は練習中に早期終了するため、位置移動を追加しても従来の練習動作を変えない。


## HTML外部プレビューの公開メッセージ契約

外部HTMLは直近の親ViewerへpostMessageする。パス・文書ID・本体IPCは渡さない。

要求: type = wasabipad-external-source-navigation、request_id = 0以上のsafe integer、source_hash = 正規化入力のUTF-8 SHA-256（小文字64桁）、offset = 正規化入力先頭から0始まりUTF-16 code unit位置。特定できない位置はnull。

正規化は先頭のBOMを1文字除去し、CRLFおよびCRをLFへ変換する。hashとoffsetには同じ入力を用いる。現在のrunnerは保存済みファイル全体を入力とするため、エディタ選択範囲の開始を加算しない。

応答: type = wasabipad-external-source-navigation-result、同じrequest_id、reason = 成功ならnull、拒否なら短い理由。外部HTMLはevent.sourceがwindow.parentであることを検証する。Viewerは外部iframeのWindowProxyを検証し、表示IDを結び付けて本体へ中継する。本体はViewerのWindowProxyとoriginを検証する。古い表示・偽送信元・不正な型は無視する。

本体は生成開始前にエディタ本文・文書世代・内容revisionを保持し、hashと現在性を検証してから全文絶対位置へ移動する。未保存本文と保存済み入力の不一致も拒否する。連続クリックでは最後の要求を優先する。本文・選択の追随更新では外部iframeを再読込しない。

楽譜利用側の制限: 圧縮.mxlはエディタ本文へXML内位置を適用できないため、再生・表示を維持して位置移動だけ不可と案内する。MusicXMLの元位置保持は同梱Python版musicxml2lyの変換hookを使用し、独自の実行形式converterが位置を出力しない場合は移動しない。LilyPondのinclude先をクリックしても別ファイルへ移動しない。
