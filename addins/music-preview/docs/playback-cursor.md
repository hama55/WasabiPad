# 再生カーソル

状態: 利用者の推奨案への合意に基づき実装。

## 動作

- ABC と LilyPond の両方を対象とする。
- 選択した曲の実際の再生時刻に対応する位置を、赤い縦線で表示する。
- 拍に合わせて滑らかに進み、改行・改ページ・繰り返しでは対応する位置へ移る。無関係な段や繰り返しの戻り先へ連続補間しない。
- 複数の五線譜がある段は、段全体を一本の線で示す。
- 再生位置の段が画面外になった場合は、自動スクロールで表示する。
- 停止・再生終了・曲変更・再生失敗時は線を消す。次の再生は先頭から始める。
- 位置対応を取得できない曲でも再生を維持し、位置表示不可の理由を表示する。推測した位置には線を出さない。
- 原稿と音符・歌詞の配置を変更せず、既存の外部 HTML プレビュー内で表示する。

## 実装の確認事項

ABC は abcjs の描画結果と時刻・位置情報を再利用する。カーソルの基準は音声の再生時刻とし、独立した時計で進めない。

LilyPond は追加の engraver・performer で曲と音符の識別情報、段の座標、演奏順の moment、実際の MIDI 出力先を記録する。MIDI のテンポ表で moment を秒へ変換し、SVG の識別情報と照合する。ファイル名やページ番号だけから曲との対応を推測しない。装飾音の時刻対応や一意でない位置は非対応として理由を表示する。

段の座標は `output-attributes` の遅延 callback で描画時に取得する。`after-line-breaking` 中に System の境界を評価すると、配置計算に干渉して上下の五線や隣の段が重なるため、この callback は変更しない。原稿側の属性 list・callback を未評価で保持し、描画時に追加属性を結合する。

記譜用 score と MIDI 用 score が別の場合、同じ音符番号や曲順から対応を推測しない。MIDI の score ID に対応する描画 score がないときは「MIDI用 score に対応する記譜用 score を特定できません。」を表示し、音声を再生する。

## 検証範囲

公開 CLI の生成 HTML と、その再生操作を検証対象とする。

- 再生時刻と線の位置、停止・終了・曲変更・失敗後の非表示。
- 改行・改ページ・繰り返し・テンポ変更・複数曲・複数五線譜での対応。
- 幅変更後の位置・高さと、画面外の段へのスクロール。
- 位置対応がない場合の説明と音声再生の維持。
- 実ブラウザーでのアニメーション・表示確認と、LilyPond の実変換。自動テストとは区別して結果を報告する。
- 同じ紙面設定でカーソル注入あり・なしの全 SVG 描画形状と座標、MIDI が一致すること。複数声部・加線・和音・タイ・三連符・改ページと原稿側 callback を含む。
